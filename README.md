# UFES

Repositório organizador de materiais e projetos acadêmicos da UFES. As
disciplinas mantidas como repositórios independentes são referenciadas por
submódulos Git.

## Clonar com os submódulos

```bash
git clone --recurse-submodules https://github.com/jhvlima/UFES.git
```

Alguns submódulos são privados e só podem ser baixados por contas autorizadas.

## Inicializar os submódulos em uma cópia existente

```bash
git submodule update --init --recursive
```
